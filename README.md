# Gladiator, Shuffle & Blitz Wins Tracker

- Adds 3 buttons to the rated PVP tab.
- Track **Gladiator**, **Shuffle Legend**, **Blitz Strategist** achievements for the current PVP season.
- View historic achievement progress.
